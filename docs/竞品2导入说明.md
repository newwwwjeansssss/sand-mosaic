## 位置与使用

- competitor2-level/：可加载关卡，文件 ID 628–1120；显示编号使用原主线/资源编号，二者不必相同。
- competitor2-level/quarantine/：异常源文件，保留原数据，不进入编辑器列表。
- competitor2-import.json：每份资源的原编号、文件路径、新 ID、适配提示及 SHA-256。
- ColorSand-1.1.9/ColorSand-1.1.9/：完整原始导出包，未修改。

刷新编辑器，在左侧选择“竞品2主线”或“竞品2其他资源”。双画面对照新增参考竞品选择，可切换竞品1/竞品2，与我们的同序号关卡对照。列表搜索支持原始资源名。

## 配色与保存

关卡的 editorMeta.palette 保存原版独立配色；不更改共享 asset.json，不改变沙粒或方块颜色编号。画布、缩略图、对照、资源色卡和沙量面板均使用关卡配色。原版0号为空色，不提供为画笔颜色。复制竞品2关卡时保留配色并放入 our-level/，不会覆盖竞品2。现有关卡仍保存到自己的目录；只有点击右上角保存才写盘。独立配色的资源卡不可用于修改共享颜色。
